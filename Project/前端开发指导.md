## 1. 概述

前端是用户与 MouseToxDB 交互的界面。前端负责：

1. 页面路由与导航
2. 全局搜索（带分类下拉）
3. 搜索结果展示与分页
4. 分析条目浏览（带侧边栏筛选）
5. 详情页多 Tab 展示（基本信息、实验、样本、图表、DEG 表格）
6. PDF 内嵌预览
7. DEG 表格分页展示
8. 文件下载（Excel / PDF / TXT）
9. 外部链接跳转

> v1 界面使用**中文**。代码结构预留 i18n 能力。

**API**：`GET /api/analysis/{analysisKey}/tables/deg-table?page=1&page_size=30`

|------|---------|------|

## 7. 外部链接规则

### 工具函数：`utils/externalLinks.ts`

```typescript
export const externalLinks = {
  pubchem: (cid: string) =>
    `https://pubchem.ncbi.nlm.nih.gov/compound/${cid}`,

  geo: (gseId: string) =>
    `https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=${gseId}`,

  sra: (srrId: string) =>
    `https://www.ncbi.nlm.nih.gov/sra/?term=${srrId}`,

  bioproject: (id: string) =>
    `https://www.ncbi.nlm.nih.gov/bioproject/${id}`,

  doi: (rawDoi: string) => {
    // 去除 "doi:" 或 "DOI：" 前缀
    const cleaned = rawDoi.replace(/^(doi:|DOI：)\s*/i, "");
    return `https://doi.org/${cleaned}`;
  },
};
```

**使用规则**：
- 所有外链在**新标签页**打开（`target="_blank" rel="noopener noreferrer"`）
- 字段值为 `null` 或空字符串时**不显示链接**，显示 "—"
- 链接文字用字段原始值（如 `GSE223464`），不显示完整 URL

## 8. 与后端的接口约定

> 本节是前端和后端对齐的核心。所有数据从后端 API 获取。

### 8.1 Axios 配置

```typescript
// src/api/index.ts
import axios from "axios";

const api = axios.create({
  baseURL: "/api",   // Nginx 反向代理到 backend:8000
  timeout: 10000,
});

export default api;
```

> **重要**：前端不直接连数据库。所有请求发往 `/api/`，由 Nginx 代理。

### 8.2 统一响应格式

所有 API 返回：
```typescript
interface ApiResponse<T = any> {
  code: number;      // 200 = 成功, 404 = 不存在, 500 = 服务器错误
  message: string;
  data: T | null;
}

interface PaginatedData<T> {
  total: number;
  page: number;
  page_size: number;
  items: T[];
}
```

### 8.3 完整 API 调用清单

| 页面 | 调用 | 返回数据 |
|------|------|---------|
| 首页 | `GET /api/stats/summary` | 统计摘要（卡片数值 + 统计图列表） |
| 搜索结果 | `GET /api/search?keyword=x&category=all&page=1&page_size=30` | 分析条目列表（分页） |
| 搜索导出 | `GET /api/search/export?keyword=x&category=all` | Excel 文件流 |
| 浏览 | `GET /api/browse?page=1&page_size=30&tissue_category=x` | 分析条目列表（分页） |
| 浏览筛选 | `GET /api/browse/filters` | 筛选选项（组织分类、建库方法、年份范围） |
| 详情 | `GET /api/analysis/{key}` | summary + sample_records + assets |
| DEG 表格 | `GET /api/analysis/{key}/tables/deg-table?page=1&page_size=30` | DEG 数据（分页） |
| 资源列表 | `GET /api/analysis/{key}/assets` | 资源列表 |
| 资源下载 | `GET /api/assets/{id}/download` | 文件流 |
| 整库下载 | `GET /api/download/database` | Excel 文件流 |

### 8.4 文件下载实现

```typescript
// 触发浏览器下载
const downloadFile = (url: string) => {
  const link = document.createElement("a");
  link.href = url;
  link.download = "";
  document.body.appendChild(link);
  link.click();
  document.body.removeChild(link);
};

// 整库下载
downloadFile("/api/download/database");

// 搜索结果导出
downloadFile(`/api/search/export?keyword=${keyword}&category=${category}`);

// 单个资源下载
downloadFile(`/api/assets/${assetId}/download`);
```

### 8.5 静态资源 URL

以下 URL 由 **Nginx 直接服务**，不经过后端 API：

| 用途 | URL 格式 | 示例 |
|------|---------|------|
| PDF 预览 | `/static/assets/{DESEQ_ID}/{filename}` | `/static/assets/DESEQ1001/DESEQ1001_PCA_plot.pdf` |
| 统计图片 | `/static/statistics/{filename}` | `/static/statistics/overall_summary.png` |

> 这些 URL 在后端 API 返回的数据中以 `preview_url` 和 `url` 字段提供，前端直接使用即可。

## 11. Docker 配置

### Dockerfile（多阶段构建）

```dockerfile
# 构建阶段
FROM node:18-alpine AS build
WORKDIR /app
COPY package*.json ./
RUN npm install
COPY . .
RUN npm run build

# 生产阶段
FROM nginx:alpine
COPY --from=build /app/dist /usr/share/nginx/html
EXPOSE 80
CMD ["nginx", "-g", "daemon off;"]
```

### Nginx 配置（由项目根目录 `nginx/default.conf` 提供）

```nginx
server {
    listen 80;
    server_name localhost;
    client_max_body_size 50M;

    # 前端 SPA
    location / {
        root /usr/share/nginx/html;
        index index.html;
        try_files $uri $uri/ /index.html;
    }

    # 后端 API
    location /api/ {
        proxy_pass http://backend:8000/api/;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    }

    # Swagger
    location /docs {
        proxy_pass http://backend:8000/docs;
    }
    location /openapi.json {
        proxy_pass http://backend:8000/openapi.json;
    }

    # PDF/TXT 静态资源
    location /static/assets/ {
        alias /data/deseq_assets/;
        autoindex off;
    }

    # 统计图片
    location /static/statistics/ {
        alias /data/statistics/;
        autoindex off;
    }
}
```

> **关键**：前端构建产物放在 Nginx 容器的 `/usr/share/nginx/html`。Nginx 同时处理前端路由（`try_files`）、API 代理和静态资源。
