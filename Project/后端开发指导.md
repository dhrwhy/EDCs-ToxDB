---

## 1. 概述

后端是前端与数据库之间的桥梁。后端负责：

1. 提供 RESTful API（FastAPI）
2. 连接 MySQL，执行查询（SQLAlchemy ORM）
3. 解析 TXT 资源文件（deg_table / plot_df）
4. 提供文件下载服务（Excel / PDF / TXT）
5. 提供数据导入脚本（Excel → MySQL、文件扫描 → 资源表）

> 本项目为**只读**系统。所有 API 均为 GET 方法。不使用 Alembic。

## 4. 配置与连接

### 4.1 环境变量（`config.py`）

```python
from pydantic_settings import BaseSettings

class Settings(BaseSettings):
    # 数据库
    MYSQL_HOST: str = "mysql"
    MYSQL_PORT: int = 3306
    MYSQL_DATABASE: str = "mousetoxdb"
    MYSQL_USER: str = "mousetoxdb"
    MYSQL_PASSWORD: str = "mousetoxdb_pass"

    # 文件路径
    ASSETS_DIR: str = "/data/deseq_assets"
    EXCEL_PATH: str = "/data/source_excel/260307小鼠双端信息全.xlsx"
    STATISTICS_DIR: str = "/data/statistics"

    @property
    def DATABASE_URL(self) -> str:
        return f"mysql+pymysql://{self.MYSQL_USER}:{self.MYSQL_PASSWORD}@{self.MYSQL_HOST}:{self.MYSQL_PORT}/{self.MYSQL_DATABASE}?charset=utf8mb4"

settings = Settings()
```

### 4.2 数据库连接（`database.py`）

```python
from sqlalchemy import create_engine
from sqlalchemy.orm import sessionmaker, DeclarativeBase
from app.config import settings

engine = create_engine(settings.DATABASE_URL, pool_pre_ping=True)
SessionLocal = sessionmaker(bind=engine)

class Base(DeclarativeBase):
    pass

def get_db():
    db = SessionLocal()
    try:
        yield db
    finally:
        db.close()
```

## 7. API 接口详细规格

> 以下是前端调用的全部接口。前端开发者也会参考本节内容。

### 7.1 搜索接口

`GET /api/search`

| 参数 | 类型 | 必填 | 默认 | 说明 |
|------|------|------|------|------|
| keyword | str | 是 | — | 搜索关键词 |
| category | str | 否 | all | 搜索分类：all / cas / inchikey / chemical_name / pubchem_cid / deseq_id |
| page | int | 否 | 1 | 页码 |
| page_size | int | 否 | 30 | 每页条数（最大 30） |

**搜索逻辑**：

| category 值 | 搜索字段 | 匹配方式 |
|------------|---------|---------|
| all | cas_id, inchi_key, pubchem_cid, deseq_id | 精确（= :keyword） |
| all | chemical_name, alternative_names, pubchem_name | 模糊（LIKE %keyword%） |
| cas | cas_id | 精确 |
| inchikey | inchi_key | 精确 |
| chemical_name | chemical_name, alternative_names, pubchem_name | 模糊 |
| pubchem_cid | pubchem_cid | 精确 |
| deseq_id | deseq_id | 精确 |

**核心逻辑**：查询 `main_records`，按 `analysis_key` GROUP BY 去重，返回分析条目级结果。

**返回 `data`**：
```json
{
  "total": 1,
  "page": 1,
  "page_size": 30,
  "items": [
    {
      "analysis_key": "DESEQ1001__90__GSE223464__PRJNA926360",
      "deseq_id": "DESEQ1001",
      "chemical_id": 90,
      "sort_id": 559,
      "cas_id": "1478-61-1",
      "chemical_name": "Bisphenol AF",
      "pubchem_cid": "7175",
      "pubchem_name": "Bisphenol AF",
      "gse_id": "GSE223464",
      "bioproject_id": "PRJNA926360",
      "organism": "Mus musculus",
      "tissue_category": "癌症",
      "library_method": "bulk_RNAseq",
      "platform": "ILLUMINA",
      "publication_year": 2017,
      "sample_count": 6,
      "has_assets": true
    }
  ]
}
```

> `sample_count` = 该 `analysis_key` 对应的 SRR 行数（COUNT 聚合）。
> `has_assets` = `record_assets` 表中是否存在该 `deseq_id` 的记录。

### 7.5 DEG 表格分页接口

`GET /api/analysis/{analysis_key}/tables/deg-table`

| 参数 | 类型 | 默认 |
|------|------|------|
| page | int | 1 |
| page_size | int | 30 |

**实现逻辑**：
1. 通过 `analysis_key` 查到 `deseq_id`
2. 构造文件路径：`{ASSETS_DIR}/{deseq_id}/{deseq_id}_deg_table.txt`
3. 读取 TSV 文件（Tab 分隔，第一行为表头）
4. 按分页参数截取
5. 返回 `data`：

```json
{
  "name": "deg_table",
  "columns": ["geneID", "baseMean", "log2FoldChange", "lfcSE", "stat", "pvalue", "padj", "-log10(P.Value)", "trend", "ENTREZID"],
  "total": 378,
  "page": 1,
  "page_size": 30,
  "items": [
    { "geneID": "Krt6b", "baseMean": 775.48, "log2FoldChange": -9.81, ... }
  ]
}
```

若文件不存在或解析失败：
```json
{
  "name": "deg_table",
  "error": "文件不存在",
  "columns": [],
  "total": 0,
  "page": 1,
  "page_size": 30,
  "items": []
}
```

### 7.6 资源列表接口

`GET /api/analysis/{analysis_key}/assets`

通过 `deseq_id` 查 `record_assets`，按 `sort_order` 排序返回。

### 7.7 单个资源下载

`GET /api/assets/{asset_id}/download`

从 `record_assets` 查出 `file_path`，返回文件流（`FileResponse`）：
- `Content-Disposition: attachment; filename="{file_name}"`
- 文件不存在返回 404

### 7.8 整库下载

`GET /api/download/database`

返回原始 Excel 文件（`FileResponse`）。文件路径从 `settings.EXCEL_PATH` 获取。

### 7.9 搜索结果导出

`GET /api/search/export`

| 参数 | 类型 | 说明 |
|------|------|------|
| keyword | str | 搜索关键词 |
| category | str | 搜索分类 |

执行与搜索接口相同的查询（不分页，取全部结果），用 pandas 生成 Excel 文件流返回。

文件名：`MouseToxDB_搜索结果_YYYYMMDD_HHMMSS.xlsx`

## 8. TXT 文件解析服务

### `services/txt_parser.py`

```python
import pandas as pd
from pathlib import Path

def parse_deg_table(file_path: str, page: int = 1, page_size: int = 30) -> dict:
    """解析 deg_table.txt 并返回分页结果"""
    p = Path(file_path)
    if not p.exists():
        return {"error": "文件不存在", "columns": [], "total": 0, "items": []}

    df = pd.read_csv(p, sep="\t")
    total = len(df)
    start = (page - 1) * page_size
    end = start + page_size
    page_df = df.iloc[start:end]

    return {
        "name": "deg_table",
        "columns": list(df.columns),
        "total": total,
        "page": page,
        "page_size": page_size,
        "items": page_df.to_dict(orient="records")
    }
```

## 11. 与数据库的接口约定

> 详见 [数据库开发指导](./数据库开发指导.md)。

### 11.1 连接配置

```
mysql+pymysql://mousetoxdb:mousetoxdb_pass@mysql:3306/mousetoxdb?charset=utf8mb4
```

Docker 环境下 hostname 为 `mysql`（docker-compose 服务名）。

### 11.2 表结构依赖

后端 ORM 模型必须与数据库表结构完全一致。如果数据库修改了字段类型或名称，后端 ORM 必须同步更新。

两张表：`main_records`（47 字段）、`record_assets`（13 字段）。

### 11.3 数据导入职责

数据导入脚本（`import_excel.py`、`scan_assets.py`）放在后端项目的 `scripts/` 目录下，但逻辑上属于数据库工作的一部分。数据库开发负责编写清洗规则，后端开发负责将其实现为 Python 脚本。
